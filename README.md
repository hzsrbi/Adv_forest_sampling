# وب‌سایت فارسی درس روش‌های پیشرفته نمونه‌برداری در جنگل

مدرس: دکتر هرمز سهرابی، دانشگاه تربیت مدرس

## انتشار در GitHub Pages

۱. در حساب GitHub خود یک مخزن عمومی **جدید و جداگانه** با نام `advanced-forest-sampling` بسازید. مخزن رزومه `hz_cv` را تغییر ندهید.
۲. فایل ZIP را از حالت فشرده خارج کنید. فایل‌ها و پوشه‌های **داخل** پوشه `forest-sampling-fa` را در ریشه مخزن بارگذاری کنید. فایل `index.html` باید مستقیماً در ریشه باشد. پوشه‌های `slides` و `assets` را نیز کامل بارگذاری کنید.
۳. در مخزن به Settings → Pages بروید. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید.
۴. شاخه `main` و پوشه `/ (root)` را انتخاب کنید و Save را بزنید.
۵. پس از انتشار، نشانی سایت برای حساب شما این خواهد بود:

https://hzsrbi.github.io/advanced-forest-sampling/

اگر نام دیگری برای مخزن انتخاب کردید، بخش آخر نشانی را متناسب با آن عوض کنید. لینک github.com صفحه فایل‌هاست؛ سایت در github.io نمایش داده می‌شود.

## ویرایش محتوا

- عنوان و توضیح جلسات و اطلاعات مدرس: `index.html`
- ظاهر و رنگ‌ها: `style.css`
- جست‌وجو و فیلترها: `script.js`
- فایل‌های اصلی اسلایدها: `slides/session-01.pdf` تا `slides/session-14.pdf`
- تصاویر جلد: `assets/session-01.jpg` تا `assets/session-14.jpg`

برای جایگزینی اسلاید، PDF جدید را با همان نام در پوشه slides بارگذاری کنید. در صورت تغییر تعداد صفحات یا جلد، آن‌ها را نیز به‌روز کنید. PDFهای موجود عین فایل‌های آپلودشده هستند.

این سایت ایستا است و نیازی به نصب، ساخت پروژه، پایگاه داده یا ورود دانشجو ندارد. بارگذاری و به‌روزرسانی فایل‌ها توسط مدرس از طریق مخزن GitHub انجام می‌شود. همه فایل‌های لازم، از جمله قلم فارسی، همراه بسته هستند.
